# 示範（before → after）

> 全部係**示範句**，數字同事實係虛構，只為展示改法。實際改稿一律用 作者嘅真實內容，缺嘅標「（需作者補）」。

## 1. Hook
❌ 大家好，我係阿明。喺 AI 時代，效率變得前所未有咁重要。今日同大家分享一個超勁嘅神器，可以幫你自動整理收據。
命中：01 自我介紹、02 時代帽子、03 預告、07 無憑 hype
✅ 呢張收據，我丟俾 AI，三秒變成 Excel。你睇。
（保留：結果先行，畫面同口白對應。）

## 2. 教學步驟
❌ 首先，我們需要打開 ChatGPT。其次，將收據的圖片上傳。最後，AI 會進行分析並輸出表格。
命中：26 書面語、16 首先其次最後（但係操作步驟，放行排序）、27 翻譯腔
✅ 第一步，開 ChatGPT。第二步，影張收據上去。第三步，AI 讀完，直接出表格。

## 3. 立場真空 → 判斷
❌ Claude 同 ChatGPT 各有優缺點，邊個好要睇你嘅需要。
命中：09
✅ 寫 code 我用 Claude，因為佢少亂作。查資料我就用 ChatGPT。
（若 作者 冇咁揀 → 標「（需作者補：你自己揀邊個？點解？）」，唔代佢決定。）

## 4. 收尾
❌ 總括而言，AI 令工作更有效率。記得 like、follow、分享，開啟小鈴鐺，我哋下次再見！
命中：33 總結罐頭、34 CTA 堆疊
✅ 想要呢份 Excel 範本？留言「收據」，我 send 俾你。

## 5. 唔可讀出
❌ 呢個模型有 3.36k 個 token，準確率 47.3%。
命中：31
✅ 稿：呢個模型有三千三百六個 token，準確率百分之四十七點三。字幕：3.36k／47.3%
