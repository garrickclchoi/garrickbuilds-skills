# 廣東話口語化對照

稿係用嚟「講」，所以用口語。字幕亦跟稿（字幕規範：中文之間唔加空格，中英交界先加）。

## 書面語 → 口語

| 書面 | 口語 | 書面 | 口語 |
|---|---|---|---|
| 的（所有格／定語） | 嘅 | 現在 | 而家 |
| 是／不是 | 係／唔係 | 今天／昨天／明天 | 今日／琴日／聽日 |
| 沒有／沒 | 冇 | 時候 | 時候／陣 |
| 什麼 | 咩 | 一點／一些 | 少少／啲 |
| 怎麼／怎樣 | 點／點樣 | 多少 | 幾多 |
| 為什麼 | 點解 | 不要 | 唔好／咪 |
| 哪裡／哪個 | 邊度／邊個 | 不用 | 唔使 |
| 這個／那個 | 呢個／嗰個 | 沒關係 | 冇所謂／唔緊要 |
| 我們／你們 | 我哋／你哋 | 有沒有 | 有冇 |
| 他／她／它 | 佢 | 能不能 | 得唔得／可唔可以 |
| 很／非常 | 好／好似…／（適量用）超 | 厲害 | 勁／叻 |
| 了（完成） | 咗 | 試試 | 試吓 |
| 正在 | 緊 | 還有 | 仲有 |
| 在（位置） | 喺 | 才 | 先 |
| 給 | 畀 | 真的 | 真係 |
| 讓／使 | 等／令 | 一起 | 一齊 |
| 和／與 | 同 | 這樣 | 咁樣／噉 |
| 還是（選擇） | 定係 | 看 | 睇 |
| 但是／然而 | 但係／不過 | 說 | 講 |
| 因此 | 所以 | 吃 | 食 |
| 對 | 啱 | 走／去 | 行／去 |

常用語氣詞（適量）：喇、啦、呀、㗎、囉、咋、啫。**一句最多一個**，唔好每句都有。

## 中英夾雜
- **工具名、指令、技術詞保留英文原樣**（OpenCode、prompt、Excel、MCP、API），唔硬譯。
- 句子骨架用廣東話。唔好整句英文，除非係引用畫面上嘅字。
- 字幕：中英交界加空格（`用 Excel 做`），中文之間唔加。

## 數字同符號嘅讀法
稿入面寫讀法，括號註明，字幕用數字：
- `3.36k` → 三千三百六
- `47.3%` → 百分之四十七點三
- `$99` → 九十九美元
- `1:1` → 一比一
- `/blueprint` → slash blueprint
- 網址：唔讀。講「睇 bio」／「留言攞 link」

## 節奏
- 平均約 **4 字／秒**。170–240 字 ≈ 40–60 秒。
- 一句一口氣，約 ≤15 字。
- 允許自然停頓同「呃」，唔係每個口誤都要消滅（見剪片規則：句子要唔要剪走由作者決定）。
